About this project

AnimeFinds is a small, independent project built to make it easier to find something new to watch — either by starting from a show you already like, or by narrowing things down with filters like genre, theme and episode count.

How it works

All anime data comes from the AniList GraphQL API. "Find similar shows" uses AniList's community-submitted recommendations for a given title. "Browse by filter" queries AniList directly for shows matching your selections. AnimeFinds is just a search tool — no accounts, no watchlists, nothing to sign up for.

Who built this

Me! Though I'd be lying if I said I did it alone — Claude did the vast majority of the actual building. My own development background helped me steer it in the right direction, though.

I built this for two reasons:

  • I like anime. Obviously.
  • Maybe someone stumbles across this and finds a new show to get invested in.
